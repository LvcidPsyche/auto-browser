# Release 1.12.2

A controller patch release over 1.12.1: the #244 fix (#246) and the four Dependabot bumps
(#239, #234, #236, #235). The three PyPI packages change only in version.

## Done (2026-11-01/02 session)

  #236 (9b94618), #235 (4eee6cd). All four were also run together on the host suite on Python 3.11,

## Left, in order

1. **Live tool_choice probe (needs `OPENROUTER_API_KEY` in the environment).** The script is on
   branch `claude/probe-tool-choice` at `scripts/probe_tool_choice.py` (standard library only; that
   branch is a carrier, never open a PR from it). Run `git fetch origin claude/probe-tool-choice &&
   git show origin/claude/probe-tool-choice:scripts/probe_tool_choice.py > /tmp/probe_tool_choice.py &&
   python3 /tmp/probe_tool_choice.py`. It sends seven OpenRouter models the controller's real request,
   named and unforced, and prints a verdict per model; worst case about $0.22, typically cents.
   - Every verdict "FIXED by #246" or "named choice accepted": nothing to change; quote the table in
     the release PR.
   - Any "NOT FIXED": the matcher misses that model's real 400. Widen `_TOOL_CHOICE_MENTION` or the
     match in `controller/app/providers/openai_compatible.py`, add the real body as a test fixture in
     `controller/tests/test_openai_compatible_provider.py`, land it as its own fix PR, then rebase this
     branch and extend the CHANGELOG entry.
2. **Re-run the release audit** from the repo root in a venv with `pip install -e ./controller[dev]`:
   `PLAYWRIGHT_BROWSERS_PATH=$(mktemp -d) python scripts/release_audit.py --skip-doctor`. The empty
   browsers path skips the real-Chromium tests: in a cloud sandbox the preinstalled Chromium is 153
   while Playwright 1.62 pins 151, and
   `test_request_gate_attach_chromium.py::test_chrome_fails_the_operators_cross_origin_post_redirect_while_the_gate_is_attached`
   fails there on unmodified main too. CI's 3.11 leg runs those tests with the right Chromium.
3. **Independent review of the release notes** (fresh context): every sentence of the `[1.12.2]`
   section against `git log v1.12.1..origin/main` and the diffs, and the release against AGENTS.md's
   Releases section and the 1.12.1 release commit (fad124c). A first attempt was interrupted by a
   container restart before reporting.
4. **Release PR** (draft opened from this branch): mark ready, green CI, squash-merge as
   `release: 1.12.2 (#N)`.
5. **Tag: the maintainer's call, not an agent's.** After the push-to-main `ci.yml` run on the merged
   release commit is green (release.yml and docker-publish.yml refuse a tag without it), the maintainer

   and the `1.12.2`, `1.12` and `latest` images. PyPI versions cannot be reused.
   If the release lands on a later day, change the CHANGELOG date first.
